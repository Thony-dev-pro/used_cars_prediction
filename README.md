# used_cars_prediction

## Dataset Features

| Column | Description |
|---|---|
| year | Year of manufacture of the vehicle. |
| manufacturer | Manufacturer or brand of the vehicle (e.g., Toyota, BMW, Ford). |
| model | Specific model of the vehicle (e.g., Corolla, 3 Series, Mustang). |
| odometer | Total distance traveled by the vehicle, usually measured in miles in this dataset. |
| fuel | Type of fuel used by the vehicle (e.g., gas, diesel, hybrid, electric). |
| transmission | Type of transmission (e.g., automatic, manual, or other). |
| title_status | Legal or administrative status of the vehicle's title (e.g., clean, salvage, rebuilt). |
| type | Body style or category of the vehicle (e.g., SUV, sedan, pickup, hatchback). |
| state | U.S. state where the vehicle listing was published. |
